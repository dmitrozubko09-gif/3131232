# Remote Control — Дистанційне керування комп'ютером

## Що це?
Повноцінне remote control подібне до AnyDesk:
- Трансляція екрану в реальному часі (~20 fps)
- Керування мишкою (рух, кліки, прокрутка)
- Керування клавіатурою (всі кнопки, хоткеї)
- Браузерний клієнт — нічого не потрібно встановлювати на іншому пристрої

---

## Встановлення (один раз)

```bash
pip install pyautogui pillow websockets
```

На Linux також потрібно:
```bash
sudo apt install python3-tk python3-dev scrot
pip install pyautogui pillow websockets
```

---

## Запуск

1. **На комп'ютері, яким хочеш керувати:**
```bash
python server.py
```

2. **На іншому пристрої** (телефон, ноутбук, планшет):
Відкрий браузер і введи:
```
http://IP_АДРЕСА_КОМП'ЮТЕРА:8080
```

Або на тому ж комп'ютері:
```
http://localhost:8080
```

3. У браузері введи WebSocket адресу:
```
ws://IP_АДРЕСА:8765
```
і натисни **Підключитись**.

---

## Знайти IP адресу

**Windows:**
```
ipconfig
```
Шукай "IPv4 Address" — щось типу `192.168.1.100`

**Linux/Mac:**
```
ip addr   або   ifconfig
```

## Можливості клієнта

| Дія | Як |
|-----|-----|
| Рух миші | Просто рухай мишу по екрану |
| Лівий клік | Клік лівою кнопкою |
| Правий клік | Клік правою кнопкою |
| Подвійний клік | Подвійний клік |
| Прокрутка | Колесо миші |
| Клавіатура | Просто печатай |
| Ctrl+C/V/Z/X | Кнопки в тулбарі або звичайне Ctrl+ |
| Alt+F4 | Кнопка в тулбарі |
| Модифікатори | Кнопки Ctrl/Alt/Shift в тулбарі |

## Безпека

⚠️ Цей сервер **не має автентифікації** — використовуй тільки в домашній мережі!

Для захисту через інтернет — використовуй SSH тунель:
```bash
ssh -L 8765:localhost:8765 -L 8080:localhost:8080 user@remote-computer
```
